# Письма о бронированиях (Resend) — пошаговая инструкция

Сайт отправляет письма через сервис **Resend**:

| Когда                          | Кому      | Письмо                                                       |
| ------------------------------ | --------- | ------------------------------------------------------------ |
| Клиент отправил заявку         | клиенту   | «Užklausa gauta» — номер заявки, даты, цена, залог (LT / EN) |
| Клиент отправил заявку         | менеджеру | детали заявки, телефон и email клиента, кнопка в админку     |
| Менеджер подтвердил / отклонил | клиенту   | «Rezervacija patvirtinta» / «nepatvirtinta» (с фазы 6)       |

**Пока Resend не настроен, бронирование всё равно работает:** заявка сохраняется в базе
(Supabase → Table Editor → `bookings`), но писем нет, и сайт не обещает клиенту письмо.
До готовности админки (фаза 6) именно письмо менеджеру — способ узнать о новой заявке,
поэтому настройте Resend до того, как давать ссылку на сайт клиентам.

Бесплатного плана Resend (3000 писем в месяц, 100 в день) для старта достаточно.

## 1. Аккаунт

1. Откройте **resend.com** → **Sign up** (удобно войти через Google).

## 2. Домен отправителя

Письма должны уходить с адреса на вашем домене (например, `rezervacijos@balticnuoma.lt`),
иначе они попадут в спам. Для этого домен нужно подтвердить DNS-записями.

1. В Resend: **Domains** → **Add Domain** → введите `balticnuoma.lt`, регион — **Ireland (eu-west-1)**.
2. Resend покажет 3–4 DNS-записи (обычно MX и TXT для `send`, TXT для `resend._domainkey`,
   иногда рекомендуемую TXT `_dmarc`). Оставьте эту страницу открытой.
3. Добавьте записи там, где управляются DNS домена:
   - если домен использует DNS Vercel: **Vercel** → вкладка **Domains** (на уровне команды) →
     `balticnuoma.lt` → **DNS Records** → **Add** для каждой записи;
   - иначе — в панели регистратора домена (раздел DNS / DNS zone).

   Копируйте **Name**, **Type**, **Value** (и **Priority** для MX) ровно так, как показывает Resend.
   Записи для подтверждения почты не мешают сайту и существующей почте.

4. Вернитесь в Resend → **Verify DNS Records**. Обычно домен подтверждается за 5–30 минут
   (иногда до нескольких часов). Статус должен стать **Verified**.

## 3. API-ключ

1. Resend → **API Keys** → **Create API Key**.
2. Name: `balticnuoma-vercel`, Permission: **Sending access**, Domain: `balticnuoma.lt` → **Add**.
3. Скопируйте ключ (начинается с `re_`) — он показывается **один раз**.
   Не отправляйте его в чат и не показывайте на скриншотах.

## 4. Переменные в Vercel

Vercel → проект → **Settings** → **Environment Variables** → добавьте (окружения: Production и Preview):

| Name                   | Value                                        | Тип           |
| ---------------------- | -------------------------------------------- | ------------- |
| `RESEND_API_KEY`       | ключ из шага 3                               | **Sensitive** |
| `EMAIL_FROM`           | `Baltic Nuoma <rezervacijos@balticnuoma.lt>` | обычная       |
| `BOOKING_NOTIFY_EMAIL` | почта менеджера, куда приходят новые заявки  | обычная       |

Затем **Deployments** → последний деплой → **⋯** → **Redeploy**.

Адрес в `EMAIL_FROM` может быть любым на подтверждённом домене — отдельный почтовый ящик для
него не нужен. Ответы клиентов уходят на email из контактов сайта (если он указан в настройках),
а ответ менеджера на письмо о заявке — сразу клиенту.

## 5. Проверка

1. Откройте любой автомобиль на сайте → выберите даты → отправьте заявку на свой email.
2. Должны прийти два письма: «Užklausa gauta» (вам как клиенту) и «Nauja užklausa» (на `BOOKING_NOTIFY_EMAIL`).
   Если нет — проверьте папку «Спам» и раздел **Emails** в Resend (там видно, что ушло и почему не дошло).
3. Удалите тестовую заявку: Supabase → **Table Editor** → `bookings` → выделите строку → **Delete**.
   Даты освободятся сразу.

## Защита формы

- Цена и доступность всегда пересчитываются на сервере; двойная бронь невозможна (проверка в базе).
- Не больше `BOOKING_RATE_LIMIT_PER_HOUR` заявок в час с одного IP (по умолчанию 5).
  IP не хранится — только его хеш.
- Скрытое поле-ловушка и проверка времени заполнения отсекают ботов.
