# Админ-панель — первый вход и работа с заявками

Админ-панель: **https://www.balticnuoma.lt/admin** (только на литовском, в поиске не индексируется).
Регистрации на сайте нет — пользователей создаёте вы в Supabase. Ролей две:

| Роль                    | Что может                                                                          |
| ----------------------- | ---------------------------------------------------------------------------------- |
| `admin` (администратор) | всё: заявки, календарь, автомобили, категории, **настройки**, удаление автомобилей |
| `manager` (менеджер)    | заявки, календарь, автомобили и категории — без настроек и удаления                |

## 1. Создать свой вход (администратор)

1. Supabase → ваш проект → **Authentication** → **Users** → **Add user** → **Create new user**.
2. Введите свой **email** и **пароль** (не короче 8 символов), отметьте **Auto Confirm User** → **Create user**.
3. Откройте **SQL Editor** → **+ New query**, вставьте (замените email и имя) → **Run**:

   ```sql
   update public.profiles
   set role = 'admin', full_name = 'Vardas Pavardė'
   where id = (select id from auth.users where email = 'jusu@pastas.lt')
   returning full_name, role;
   ```

   Внизу должна появиться одна строка с вашим именем и `admin`. Если строк нет — проверьте email.

4. Откройте https://www.balticnuoma.lt/admin и войдите.

## 2. Вход для менеджера

Проще всего — в самой админке: **Nustatymai → Naudotojai → Naujas naudotojas** (имя, email, временный
пароль не короче 10 символов, роль «Vadybininkas»). Передайте менеджеру email и пароль — сменить пароль
он сможет сам: имя внизу меню → **Mano paskyra**. Там же администратор может задать новый пароль любому
пользователю, если его забыли.

## 3. Проверьте настройки Supabase Auth (один раз)

- **Authentication → Sign In / Providers → Email**: выключено **Allow new users to sign up**
  (чтобы никто посторонний не мог создать себе вход).
- **Authentication → URL Configuration → Site URL**: `https://www.balticnuoma.lt`.

## Как работать с заявками

- **Apžvalga** — новые заявки, кто берёт / возвращает авто сегодня и завтра, загрузка автопарка.
- **Rezervacijos** — все заявки и брони: фильтры по статусу, автомобилю, датам, поиск по имени,
  телефону, email или номеру `BN-…`, выгрузка в **CSV** (открывается в Excel).
- Карточка заявки:
  - **Patvirtinti** — даты занимаются, в календаре сайта становятся красными, клиенту уходит письмо
    «Rezervacija patvirtinta». Если на эти даты уже есть подтверждённая бронь или блокировка, подтвердить
    не получится — система скажет об этом.
  - **Atmesti** — с причиной (есть готовые варианты; если клиент писал по-английски, причину пишите
    по-английски — письмо уйдёт на его языке).
  - После подтверждения кнопка **«Atmesti kitas užklausas šioms datoms»** одним нажатием отклонит
    остальные заявки на те же даты (клиенты получат письмо «даты уже заняты»).
  - **Atšaukti rezervaciją** — освобождает даты; письмо клиенту не отправляется, сообщите ему сами.
  - **Vadybininko pastaba** — заметка, видна только в админке.
- **Nauja rezervacija** (кнопка в «Rezervacijos», на главной и в календаре) — для клиентов, которые звонят
  или пишут по объявлению. Обязательны только имя, фамилия и телефон. Справа сразу видно цену по
  тарифам и свободны ли даты; цену и залог можно изменить (скидка, договорённость). Бронь сохраняется
  сразу **подтверждённой** (даты занимаются) или как «Laukia patvirtinimo». Если указан email — можно
  отправить клиенту письмо-подтверждение на LT или EN. В списке такие брони помечены «Telefonu».
  В календаре: щёлкните пустой день → «Sukurti rezervaciją šioms datoms».
- **Kalendorius** — все автомобили по дням: оранжевые — заявки (даты не занимают), красные —
  подтверждённые брони, серые — блокировки. Щёлкните по пустому дню, чтобы **заблокировать** даты
  (ТО, ремонт, личное использование); щёлкните по блокировке, чтобы её снять.
- Новые заявки появляются в админке сразу, без обновления страницы.

С телефона всё тоже работает — меню открывается кнопкой справа вверху.

## Автомобили

- **Automobiliai → Pridėti automobilį** — сразу создаётся черновик, всё сохраняется автоматически
  (вверху видно «Išsaugota»). Три шага:
  1. **Pagrindinė informacija** — категория, марка и модель (подсказки из справочника, можно ввести новую —
     она добавится сама), год, кузов, номер, название (подставляется из марки и модели), адрес страницы,
     описание LT/EN, технические данные, свои поля («Masažinės sėdynės — Taip»), оснащение с иконками.
  2. **Nuotraukos** — перетащите фото или выберите с телефона; они сжимаются автоматически. Порядок —
     перетаскиванием или стрелками, **Viršelis** — главное фото, подписи LT/EN для поиска и доступности.
  3. **Kainos ir paskelbimas** — пустые поля = цены и требования категории; заполните только то, что у этой
     машины отличается (например, свой залог или без почасовой аренды). Статус: **Paskelbta** — на сайте,
     **Paslėpta** / **Remontas** — скрыта, **Juodraštis** — в работе.
- **Dubliuoti** — копия с фото и ценами (удобно для одинаковых машин); копия сохраняется черновиком.
- Удалить машину может только администратор и только без истории броней — иначе поставьте «Paslėpta».

## Категории и настройки

- **Kategorijos** — классы авто (Ekonominė, Premium, Prabangi или новые): название LT/EN, цены и требования
  по умолчанию для всех машин категории.
- **Nustatymai** (только администратор) — общие тарифы и залог, требования к водителю, контакты на сайте,
  email для уведомлений о заявках, часы работы. Изменения видны на сайте сразу.
- Порядок наследования: **общие настройки → категория → автомобиль** (каждый уровень меняет только то,
  что в нём заполнено).
